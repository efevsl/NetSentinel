# NetSentinel

Windows için küçük bir komut satırı (batch) aracı. Yönetici yetkisiyle çalışır ve basit bir menü üzerinden belirli NetSupport eklenti servislerini durdurur.

> Not: Araç, çalıştığı bilgisayardaki ilgili servisleri kapatır. Yalnızca kendi cihazında / yetkili olduğun ortamlarda kullan.

## Kullanım

1. `NetSentinel.bat` dosyasına çift tıkla.
2. Windows yönetici izni ister — onayla.
3. Menüden seçim yap.
